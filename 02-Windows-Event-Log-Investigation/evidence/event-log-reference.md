Windows Event Log Reference

Event ID 4624 — Successful Logon

Indicates that a user successfully logged on to a Windows system.

Event ID 4625 — Failed Logon

Indicates that a logon attempt failed.

Event ID 4672 — Special Privileges Assigned

Indicates that special privileges were assigned to a new logon session.

Event ID 4688 — Process Creation

Indicates that a new process was created.

Event ID 1102 — Audit Log Cleared

Indicates that the Windows Security audit log was cleared.

Investigation Use

These Event IDs help SOC analysts investigate authentication activity, privilege usage, process execution and potential security incidents.
