Windows Event Log Investigation

1. Project Overview

This project demonstrates a practical Security Operations Center (SOC) investigation using Windows Security Event Logs.

The objective is to analyse Windows authentication activity, investigate suspicious login attempts, examine process creation events, and document security findings.

Note: This project uses sample and simulated event data for educational purposes. No real production systems were accessed.

2. Investigation Objectives

- Analyse successful and failed login attempts.
- Identify suspicious authentication patterns.
- Understand important Windows Security Event IDs.
- Investigate process creation activity.
- Build an event investigation timeline.
- Document findings and recommendations.

3. Tools and Technologies

- Windows Security Event Logs
- Windows Event Viewer concepts
- GitHub
- Sample event log data
- MITRE ATT&CK Framework
