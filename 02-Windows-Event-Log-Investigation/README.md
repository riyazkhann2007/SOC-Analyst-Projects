Windows Event Log Investigation

Project Overview

This project demonstrates a practical Security Operations Center (SOC) investigation using Windows Security Event Logs.

The objective is to identify suspicious login activity, analyse Windows Event IDs, investigate potential brute-force attempts, and document findings.

Investigation Objectives

- Identify failed login attempts.
- Identify successful logins.
- Analyse Windows Security Event IDs.
- Build an investigation timeline.
- Determine whether suspicious activity requires escalation.

Tools Used

- Windows Security Event Logs
- Event Viewer concepts
- GitHub
- Sample Windows Event Log dataset

Event IDs to Investigate

Event ID| Description

4625| Failed logon
4672| Special privileges assigned
